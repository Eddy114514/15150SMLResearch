Shared finite command descriptions:
type CommandCase.bindings = (string * int) list
datatype CommandCase.action = Assign of string * int | Break | Continue | Return of int | If of bool * CommandCase.action list * CommandCase.action list | Loop of string * int * CommandCase.action list
datatype CommandCase.outcome = Completed of CommandCase.bindings | Broke of CommandCase.bindings | Continued of CommandCase.bindings | Returned of int
Qualify constructors with CommandCase. Input bindings are assignment history (latest assignment wins). Actual outcome environments are lookup tables (first binding wins), so compare observations rather than list representation. Completed is ordinary completion; Broke and Continued are uncaught control signals for an enclosing loop body; Returned carries the return integer. Ordinary unexpected exceptions are execution errors.
- CommandModel.writes : string -> CommandCase.action -> bool. Whether any branch writes the name or initializes a loop counter with it. No preconditions.
- CommandModel.valid : CommandCase.action -> bool. Reference-subset check: bodies do not assign/reuse that loop's counter, recursively. Negative counts are allowed and execute zero iterations. This is not equivalent to the original well-formed-program precondition. No preconditions.
- CommandModel.expected : CommandCase.bindings -> CommandCase.action -> CommandCase.outcome. Independent finite interpreter with assignment-history environments. Requires valid action. Loops initialize counter=0, increment before body, consume Continue, consume Break and propagate Return.
- CommandModel.commands : CommandCase.bindings -> CommandCase.action list -> CommandCase.outcome. Sequential reference interpretation stopping at first control signal; requires each action valid.
- CommandModel.matches : CommandCase.bindings -> CommandCase.bindings -> bool. Compare reference assignment history with actual first-binding environment by visible lookup for the union of names. No preconditions.
The adapter builds original arithmetic/boolean ASTs for this constant/counting slice. It catches precisely BreakExn, ContinueExn and ReturnExn. It does not evaluate arbitrary full programs, parse text, or prove arbitrary loops terminate. The original requires refers to the enclosing complete program, including eventual Return and legal loop context. That context is absent from the adapter input, so the full specification is unsupported. The independent finite reference and its domain labels describe only the declared subset; they are not an oracle for the original precondition.
